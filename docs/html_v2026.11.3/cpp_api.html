Core Engine & CLI Dispatcher¶

DataLogger¶

class DataLogger¶

High-throughput C++17 SNMP Data Logger engine.

Orchestrates concurrent SNMP polling across configured Devices Under Test (DUTs), buffers collected Batch objects through a bounded lock-protected queue, and fans telemetry out to CSV, JSONL, SQLite3, PostgreSQL, and Prometheus HTTP sinks.

Designed with a clean PIMPL boundary so SWIG 4.x can expose DataLogger directly to Python, JavaScript/Node.js, Java, C#, Go, Ruby, Perl, PHP, Lua, R, Tcl, Octave, D, Guile, and Scilab.

EzSnmp Polling Layer¶

EzSnmpPoller delegates all SNMPv1, SNMPv2c, and SNMPv3 get, getnext, walk, bulkget, bulkwalk, and set requests to ezsnmp’s C++17 SessionBase and Result classes, normalizing returned bindings into Sample and Batch records.

class EzSnmpPoller : public ezsnmp_data_logger::ISnmpPoller¶

Poller backed directly by ezsnmp’s C++17 SessionBase and Result layer.

Delegates all Net-SNMP session management, SNMPv1/v2c/v3 USM authentication & privacy, thread-safe MIB formatting, and GET/GETNEXT/WALK/BULKGET/BULKWALK/SET operations to the sibling ezsnmp library (SessionBase), converting returned Result objects into ezsnmp_data_logger::Sample records for storage in the data_logger layer.
