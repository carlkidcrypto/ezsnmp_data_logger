Python API Reference¶

This page documents the Python package ezsnmp_data_logger, its CLI entry point, and the cross-platform GUI modules (CliSubprocessBridge and StudioHttpServer) that drive the CLI behind the scenes across Linux, macOS, and Windows.

CLI Module (ezsnmp_data_logger.cli)¶

Command-line entry point for ezsnmp_data_logger (delegates to C++17 CliRunner or GUI).

GUI Launcher (ezsnmp_data_logger.gui)¶

Cross-platform Graphical User Interface launcher for ezsnmp_data_logger.

Supports Linux, macOS, and Windows via: 1. tk: Native cross-platform desktop application (tkinter.ttk), or 2. web: Cross-platform Browser Studio (http.server + HTML5/SVG).

Both frontends interact strictly with the ezsnmp-data-logger CLI behind the scenes and store 100% of configuration and GUI settings in JSON.

log_message(format: str, *args: Any) → None[source]¶

Log an arbitrary message.

This is used by all other logging functions. Override it if you have specific logging wishes.

The first argument, FORMAT, is a format string for the message to be logged. If the format string contains any % escapes requiring parameters, they should be specified as subsequent arguments (it’s just like printf!).

The client ip and current date/time are prefixed to every message.

Unicode control characters are replaced with escaped hex before writing the output to stderr.
